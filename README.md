# 💰 Expense Tracker

A simple command-line Expense Tracker built with Python.

## Features

- Add expenses
- Show all expenses
- Calculate total expenses
- Delete expenses
- Save data using JSON
- Load saved data automatically

## Technologies

- Python
- JSON
- File Handling

## How to Run

```bash
python main.py
```
